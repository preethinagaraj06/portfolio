# Preethi N - Professional Portfolio

A clean, professional fresher portfolio based on the same simple template style as the reference provided by Preethi.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Clean white-card layout
- Professional header and navigation
- Responsive design for mobile and desktop
- About Me section
- Education
- Technical skills and core skills
- Detailed CrisisBridge project
- Internship experience
- Certifications
- Participation and languages
- Contact section
- GitHub, LinkedIn and LeetCode links
- Small JavaScript navigation enhancement
- Automatic copyright year

## Project Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally

Open the folder in VS Code and open `index.html` in a browser.

For development, you can use the Live Server extension in VS Code.

## GitHub Pages

Repository name:

`portfolio`

Commands:

```bash
git add .
git commit -m "Update professional portfolio"
git push
```

Then enable GitHub Pages:

**Settings → Pages → Deploy from a branch → main → / (root)**
